# Code of Conduct

Be respectful, be constructive, assume good faith. Harassment, personal
attacks, and discriminatory language aren't tolerated in issues, PRs, or
discussions. Violations can be reported to the maintainers via the contact
in SECURITY.md.

This is a short, working policy for an early-stage project, adapted from
the Contributor Covenant. Expect it to be replaced with the full Covenant
text as the contributor base grows.
